Manager API Guide

The Manager APIs allow you to monitor team performance, approve leave requests, and manage project tasks effectively.

Update Leave Status

Approve or reject a leave request from your team. A rejection reason is required if rejecting.

// Approve a leave request
fetch('http://localhost:5000/api/manager/leaves/69b53cb.../status', {
  method: 'PUT',
  headers: { 
    'Authorization': 'Bearer YOUR_MANAGER_TOKEN',
    'Content-Type': 'application/json' 
  },
  body: JSON.stringify({ 
    status: "approved" 
  })
})
  .then(res => res.json())
  .then(json => console.log(json));

// Reject a leave request
fetch('http://localhost:5000/api/manager/leaves/69b53cb.../status', {
  method: 'PUT',
  headers: { 
    'Authorization': 'Bearer YOUR_MANAGER_TOKEN',
    'Content-Type': 'application/json' 
  },
  body: JSON.stringify({ 
    status: "rejected",
    rejectionReason: "Project deadline approaching"
  })
})
  .then(res => res.json())
  .then(json => console.log(json));
👇 Output 
{
  "_id": "69b53cb...",
  "status": "approved",
  "totalDays": 3
}

Apply Leave (Self-Service)

Managers can also apply for leave for themselves. This requires `multipart/form-data` if an attachment is included.

const formData = new FormData();
formData.append('leaveType', 'CL');
formData.append('fromDate', '2026-03-25');
formData.append('toDate', '2026-03-27');
formData.append('session', 'full-day');
formData.append('reason', 'Personal work');
// formData.append('attachment', fileInput.files[0]); // Optional

fetch('http://localhost:5000/api/manager/leaves', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer YOUR_MANAGER_TOKEN' },
  body: formData
})
  .then(res => res.json())
  .then(json => console.log(json));
