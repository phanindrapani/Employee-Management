Client API Guide

The Client APIs allow clients to track project progress, raise support tickets, and interact with the support team.

Project Management

Get My Projects

Retrieve a list of all projects associated with your account.

fetch('http://localhost:5000/api/client/tickets/projects', {
  method: 'GET',
  headers: { 'Authorization': 'Bearer YOUR_CLIENT_TOKEN' }
})
  .then(res => res.json())
  .then(json => console.log(json));

Create Ticket

Raise a new support ticket. You can optionally include attachments.

fetch('http://localhost:5000/api/client/tickets', {
  method: 'POST',
  headers: { 
    'Authorization': 'Bearer YOUR_CLIENT_TOKEN',
    'Content-Type': 'application/json' 
  },
  body: JSON.stringify({
    title: "Access Issue",
    description: "I cannot see the 'API Migration' project in my list.",
    category: "SUPPORT",
    priority: "MEDIUM",
    projectId: "6992adfb..."
  })
})
  .then(res => res.json())

Reopen Ticket

Reopen a resolved or closed ticket if the issue persists.

fetch('http://localhost:5000/api/client/tickets/69be3f2.../reopen', {
  method: 'PATCH',
  headers: { 
    'Authorization': 'Bearer YOUR_CLIENT_TOKEN',
    'Content-Type': 'application/json' 
  },
  body: JSON.stringify({ reason: "Issue still persists after fix" })
})
  .then(res => res.json())
  .then(json => console.log(json));
👇 Output 
{
  "message": "Ticket reopened"
}
