Admin API Guide

The Admin APIs provide full control over the system, including managing departments, clients, employees, and tracking attendance.

Attendance Management

Get Attendance Report

Fetch the attendance report for a specific date.

fetch('http://localhost:5000/api/admin/attendance?date=2026-03-16', {
  method: 'GET',
  headers: { 'Authorization': 'Bearer YOUR_ADMIN_TOKEN' }
})
  .then(res => res.json())
  .then(json => console.log(json));
👇 Output 
{
  "date": "2026-03-16",
  "summary": { "Present": 0, "Late": 0, "Half-Day": 0, "Absent": 49 },
  "records": [
    {
      "user": {
        "_id": "6992adfa33543e3dc970002c",
        "name": "Sarah Jenkins",
        "email": "sarah.tl@ems.com",
        "role": "employee",
        "department":"6992adf933543e3dc970001e",
        "team":"69b527f8a51569b3e2d64e32"
      },
      "date":"2026-03-15T18:30:00.000Z",
      "status":"Absent",

      "checkOut":null,
