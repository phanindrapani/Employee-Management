Employee API Guide

Comprehensive documentation for Employee workflows including attendance, tasks, leaves, and daily worksheets.

Attendance Management

Track your daily clock-in/out. Geolocation verification is required within a 600m radius of the office coordinates.

Check In

Mark your daily arrival at the office. This validates your location and records the current timestamp.

fetch('http://localhost:5000/api/employee/attendance/check-in', {
  method: 'POST',
  headers: { 
    'Authorization': 'Bearer YOUR_TOKEN',
    'Content-Type': 'application/json' 
  },
  body: JSON.stringify({ latitude: 16.3070833, longitude: 80.4281497 })
})
  .then(res => res.json())
  .then(json => console.log(json));
👇 Output 
{
  "_id": "69be4...",
  "status": "Present",
  "checkIn": "2026-03-21T09:30:00.000Z",
  "date": "2026-03-21T00:00:00.000Z",
  "checkInLocation": { "latitude": 16.3070833, "longitude": 80.4281497 }
}
❌ Error Response (403/400/500) 
// 403: Outside office range
{ "message": "You are outside office range (850m away, allowed 200m)" }
// 400: Duplicate Check-in
{ "message": "Already checked in for today" }
// 500: Server Error
{ "message": "Failed to check in" }

Check Out

Mark your departure for the day. This will automatically calculate your total working hours and update your attendance status.

fetch('http://localhost:5000/api/employee/attendance/check-out', {
  method: 'POST',
  headers: { 
    'Authorization': 'Bearer YOUR_TOKEN',
    'Content-Type': 'application/json' 
  },
  body: JSON.stringify({ latitude: 16.3070833, longitude: 80.4281497 })
})
  .then(res => res.json())
  .then(json => console.log(json));
👇 Output 
{
  "_id": "69be4...",
  "status": "Present",
  "checkIn": "2026-03-21T09:30:00.000Z",
  "checkOut": "2026-03-21T18:30:00.000Z",
  "workingHours": 9.0,
  "checkOutLocation": { "latitude": 16.3070833, "longitude": 80.4281497 }
}
❌ Error Response (403/400/500) 
// 403: Location Required
{ "message": "Location is required for attendance" }
// 400: Sequence Error
{ "message": "Check in first before check out" }
// 400: No Check-in Found
{ "message": "No check-in found for today" }
// 500: Server Error
{ "message": "Failed to check out" }

Leave Management

Manage your leave requests, check status, and calculate working days for potential leaves.

Calculate Leave Days

Calculate the total working days (excluding weekends and holidays) for a specific date range.

fetch('http://localhost:5000/api/employee/leaves/calculate', {
  method: 'POST',
  headers: { 
    'Authorization': 'Bearer YOUR_TOKEN',
    'Content-Type': 'application/json' 
  },
  body: JSON.stringify({
    fromDate: "2026-04-10",
    toDate: "2026-04-15",
    session: "full-day"
  })
})
  .then(res => res.json())
  .then(json => console.log(json));
👇 Output 
{
  "totalDays": 5
}
❌ Error Response (400/500) 
// 400: Missing Dates
{ "message": "From date and To date are required" }
// 400: Invalid Range
{ "message": "To date cannot be before From date" }
// 500: Server Error
{ "message": "Internal server error" }

Apply Leave

Submit a new leave request. Note: If an attachment is required, use multipart/form-data instead of JSON.

fetch('http://localhost:5000/api/employee/leaves', {
  method: 'POST',
  headers: { 
    'Authorization': 'Bearer YOUR_TOKEN',
    'Content-Type': 'application/json' 
  },
  body: JSON.stringify({
    leaveType: "CL", // CL, SL, EL, LOP
    fromDate: "2026-04-10",
    toDate: "2026-04-15",
    session: "full-day", // full-day, half-morning, half-afternoon
    reason: "Going to hometown",
    attachment: "null" // Send as string "null" or omit if no file
  })
})
  .then(res => res.json())
  .then(json => console.log(json));
👇 Output 
{
  "_id": "65ab...",
  "leaveType": "CL",
  "fromDate": "2026-04-10T00:00:00.000Z",
  "toDate": "2026-04-15T00:00:00.000Z",
  "totalDays": 5,
  "status": "pending",
  "reason": "Going to hometown",
  "attachment": "https://res.cloudinary.com/..."
}
❌ Error Response (400/500) 
// 400: Missing Fields
{ "message": "All fields are required (leaveType, fromDate, toDate, reason)" }
// 400: Invalid Range
{ "message": "To date cannot be before From date" }
// 400: No Working Days
{ "message": "Selected duration has no working days (Sundays/Holidays)" }
// 400: Overlap/Validation
{ "message": "Insufficient CL balance" }
// 400: Past Date
{ "message": "Cannot apply leave for past dates" }
// 500: Server Error
{ "message": "Internal server error" }
