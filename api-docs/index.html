Authentication Guide

The Authentication API allows you to register new users, log in to the system, and manage your user profile.

Register User

Create a new user account in the system.

fetch('http://localhost:5000/api/auth/register', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name: "Alex Smith",
    email: "alex@example.com",
    password: "securepassword123",
    role: "employee",
    phone: "9876543210",
    company: "ABC Technologies"
  })
})
  .then(res => res.json())
  .then(json => console.log(json));
👇 Output 
{
  "_id": "69b9270...",
  "name": "Alex Smith",
  "email": "alex@example.com",
  "role": "employee",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
❌ Error Response (400) 
// User already exists
{ "message": "User already exists" }
// Invalid user data
{ "message": "Invalid user data" }
// Validation Error
{ "message": "Validation failed" }

Login User

Authenticate and receive a JWT token.

fetch('http://localhost:5000/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: "alex@example.com",
    password: "securepassword123"
  })
})
  .then(res => res.json())
  .then(json => console.log(json));
👇 Output 
{
  "_id": "69b9270...",
  "name": "Alex Smith",
  "email":"alex@example.com",
  "role":"employee",
  "createdAt":"2026-03-17T10:03:45.020Z",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
❌ Error Response (401/500) 
// 401: Invalid Credentials
{ "message": "Invalid email or password" }
// 500: Server Error
{ "message": "Server error during login" }

Get User Profile

Retrieve details of the authenticated user.

fetch('http://localhost:5000/api/auth/profile', {
  method: 'GET',
  headers: { 'Authorization': 'Bearer YOUR_TOKEN' }
})
  .then(res => res.json())
  .then(json => console.log(json));

Update Profile

Update your profile securely.

fetch('http://localhost:5000/api/auth/profile', {
  method: 'PUT',
  headers: { 
    'Authorization': 'Bearer YOUR_TOKEN',
    'Content-Type': 'application/json' 
  },
  body: JSON.stringify({
  "phone": "8776543211"
})
})
  .then(res => res.json())
  .then(json => console.log(json));

Change Password

Update your password securely.

fetch('http://localhost:5000/api/auth/change-password', {
  method: 'POST',
  headers: { 
    'Authorization': 'Bearer YOUR_TOKEN',
    'Content-Type': 'application/json' 
  },
  body: JSON.stringify({
  "currentPassword": "securepassword123",
  "newPassword": "newpassword123"
})
})
  .then(res => res.json())
  .then(json => console.log(json));
👇 Output 
{
  "message": "Password updated successfully"
}
❌ Error Response (400/401/404/500) 
// 400: Missing Password
{ "message": "Current and new password are required" }
// 401: Incorrect Password
{ "message": "Current password is incorrect" }
// 404: Not Found
{ "message": "User not found" }
// 500: Server Error
{ "message": "Server error during password change" }
