Teamlead API Guide

The Teamlead APIs provide tools for monitoring team productivity, managing project milestones, and processing leave requests for your team members.

Team Dashboard

Team Dashboard Stats

View real-time statistics, productivity trends, and critical alerts for your assigned team.

fetch('http://localhost:5000/api/team-lead/stats', {
  method: 'GET',
  headers: { 'Authorization': 'Bearer YOUR_TEAMLEAD_TOKEN' }

Update Leave Status

Approve or reject a team member's leave request.
Note: On approval, the leave balance will be automatically debited. Rejection reason is mandatory. 

fetch('http://localhost:5000/api/team-lead/leaves/69b52a82fb2e944dff32017c/status', {
  method: 'PATCH',
  headers: { 
    'Authorization': 'Bearer YOUR_TEAMLEAD_TOKEN',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ 
    status: "approved", 
    rejectionReason: "" 
  })
})
  .then(res => res.json())
  .then(json => console.log(json));
👇 Output 
{
  "_id": "69b52a82fb2e944dff32017c",
  "status": "approved",
  "totalDays": 1,
  "balanceApplied": true
}
❌ Error Response (400/404/500) 
// 400: Rejection Reason Mandatory
{ "message": "Rejection reason is mandatory" }
// 400: Request already processed
{ "message": "Leave request already processed" }
// 400: Insufficient Balance
{ "message": "Insufficient CL balance" }
// 404: Not Found
{ "message": "Leave request not found" }
// 400: User associated with this leave no longer exists
{ "message": "User associated with this leave no longer exists" }
// 500: Server Error
{ "message": "Failed to update leave status" }
